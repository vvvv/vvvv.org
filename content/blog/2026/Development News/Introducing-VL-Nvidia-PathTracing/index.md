Hey hey, what's new?

Real-time path tracing is now available in vvvv gamma, powered by what may well be the best real-time path tracer in the world right now. It brings path-traced output into your favorite live patching workflow.

![A dense field of GPU-generated forms rendered with VL.Nvidia.PathTracing](hero.jpg)

You can combine regular meshes, GPU-generated geometry and procedural SDFs in the same scene.

![A gallery of procedural forms, materials and instanced geometry rendered with VL.Nvidia.PathTracing](geometry-gallery.jpg)

Meshes can come from Stride or be generated by compute and mesh shaders.

Procedural SDFs receive the same lighting as triangle meshes.

Text can be rendered as mesh or SDF geometry, with font, glyph and instancing support. This makes even more creative designs possible.

### Agent skills

The package comes with agent skills for writing shaders and navigating the examples. An agent can now build almost the entire scene for you. It still needs supervision, of course, but generating the shaders should work quite well.

### Technical features

- RTXPT path tracing: ReSTIR DI/GI with RTXDI reservoir-based light sampling
- DLSS Super Resolution + Ray Reconstruction: DLSS-RR replaces the denoiser at quality presets
- SER: Reorders shader execution to achieve better performance
- NRD denoising: ReLAX/ReBLUR for non-DLSS-RR modes
- DX12 Bridge: DX11/DX12 interop, so all of the above works inside vvvv gamma today

### Installation

Installation is straightforward. Use:

    nuget install VL.Nvidia.PathTracing -pre

### Requirements

- Minimum: RTX 30 series (Ampere)
- Recommended: RTX 40 series (Ada)
- RTX 20 series (Turing) has DXR support and may run
- Latest [drivers](https://www.nvidia.com/en-us/drivers/) that support shader model 6.9
