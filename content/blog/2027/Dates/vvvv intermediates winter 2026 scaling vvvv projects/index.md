In this session, [Randall Vásquez](https://thenodeinstitute.org/instructor/randall-vasquez?utm_source=vvvv&utm_medium=blog) takes you from patching alone to running a vvvv project as a team. The topics range from using git with patches and resolving merge conflicts with VLMergeTool to structuring and naming files so parallel work stays out of trouble, pinning dependencies and vvvv versions so projects still run years later, and contributing back to community libraries. By the end, you can set up a project a whole team can work on, starting from your own template repository. No prior git experience needed.

The session takes place on **February 2nd** (Tuesday), **18:00 to 21:00 CET**. It runs live and online, and the recording stays available for at least a year afterwards.

## About the instructor

**Randall Vásquez** is a systems engineer by training and a creative technologist by choice, with 20+ years in software and code running inside museum and VR installations such as Ocean of Air and Museum of the Future with Marshmallow Laser Feast. Author and maintainer of VL.OpenCV since 2017, Randall teaches the pragmatic side of architecture: how real projects get built, shipped and maintained.
